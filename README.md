# Peng Jiang personal portfolio

A responsive, accessible personal learning portfolio built with HTML, CSS and
JavaScript. No build step, external fonts, analytics, forms or third-party scripts
are required. Serve `index.html` using GitHub Pages from the repository's root.

The page includes keyboard-operable topic tabs, a mobile navigation menu,
reduced-motion support and a skip link. Its network illustration is inline SVG.

The content describes learning interests. It does not claim professional
experience, qualifications, awards or completed projects that have not been
provided or verified. AI assistance was used for implementation and editing.
